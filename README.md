Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

This repository contains my Week 4 Python assignment on functions, parameters, return statements, and default values.

Files

- welcome.py - Defines a welcome() function that returns a greeting for different students.
- toolbox.py - Contains three functions: double(), is_pass(), and greet().

What I Learned

I learned how to define functions using "def", pass information through parameters, return results, and use default parameter values.

The hardest function to write was "greet()" because it required understanding how to use a default parameter while also allowing a different greeting to be provided.
